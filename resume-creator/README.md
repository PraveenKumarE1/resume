# Resume Creator

A simple browser-based resume builder that lets users enter their details and instantly generate a professional A4 resume.

## Features

- Live resume preview
- Personal information, education, skills, projects, experience and certifications
- Add/remove multiple entries
- Local browser storage
- Clear saved data
- Print or save as PDF using the browser's print dialog
- Responsive design
- No backend and no external libraries

## Run locally

Open `index.html` in any modern browser.
