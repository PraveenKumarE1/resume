# Praveen Kumar — Portfolio

Personal portfolio website for Praveen Kumar. The site is a responsive, static HTML/CSS/JavaScript portfolio and can be deployed with GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. GitHub will provide the published site URL.

## Included

- Responsive portfolio layout
- About, selected work, skills, résumé, and contact sections
- Links to public GitHub projects and LinkedIn profile
- Mobile navigation
- Résumé PDF served from the repository
